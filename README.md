// Task Management Web Application

//Description

A full-stack task management web application where users can create, view, update, and delete tasks.  
The project demonstrates frontend–backend interaction using REST APIs and persistent storage using MongoDB.



//Features
 Create tasks with title, description, and status
 View all tasks in a clean UI
 Update existing tasks
 Delete tasks
 Input validation using Mongoose
 Responsive and modern UI using CSS



//Tech Stack
*Frontend*
 HTML
 CSS
 JavaScript

*Backend*
 Node.js
 Express.js

*Database*
 MongoDB
